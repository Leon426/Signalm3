# Signalm3 - Material 3 现代化全面 UI 重构需求文档

## 1. 项目定位与背景
Signalm3（基于 Signal-Android 官方代码库 Fork）需要进行全面的现代化 UI 视觉升级与交互重构。目标是保留 Signal 工业级的端到端加密、底层通信协议、数据存储与核心业务逻辑不变（“后端保持对齐”），将上层用户界面全面升级为最新 **Material 3 (Expressive / Beta 组件库)** 与 **Jetpack Compose**，打造视觉极具表现力、动效丝滑流畅的下一代隐私通讯应用。

## 2. 核心决策与需求边界（已澄清确认）
1. **重构范围（第一阶段聚焦核心链路）**：
   - **会话列表页（Conversation List）**：搜索栏、置顶会话、未读角标、动态波纹头像、滑动操作（归档/锁定/静音）、新建会话 FAB。
   - **聊天详情页（Chat Thread）**：现代多形态气泡流（文字/富媒体/语音波形/阅后即焚计时/引用回复）、沉浸式输入栏（麦克风⇄发送图标动态平滑形变、表情贴纸底板、媒体附件选择）。
   - **联系人列表（Contacts）**：字母索引吸顶分组、搜索与添加好友。
   - **设置中心（Settings）**：外观偏好设置（动态色、主题切换、动效档位）、隐私与安全中心、数据存储。
   - （*音视频通话、Stories 故事流、设备管理等在后续阶段推进*）。
2. **技术栈路线**：
   - **纯 Jetpack Compose (Material 3 Beta/最新组件库)** 实现核心界面，逐步替换旧有 XML View/Fragment 体系。
   - 保留原有的 Signal ViewModel、Repository、SQLCipher 加密数据库及端到端加密协议管道（底层逻辑完全对齐）。
3. **品牌色与视觉规范**：
   - **完全动态取色为主（Dynamic Color）**，辅以高表现力 Expressive 调色板与静态保底机制。
   - 大圆角、形状变形（`graphics-shapes` 多边形头像）、弹性弹簧物理动效。
